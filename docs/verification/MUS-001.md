## 限制及后续缺陷

- **已确认而未修复的权限问题**：pending 媒体、static uploads、软删除后的媒体，匿名请求均 HTTP 200。真实 Range 请求返回 206，只证明媒体传输支持，不证明授权正确。MUS-001-R1 独立审核，MUS-005 对外接入前治理。
- Druid 1.2.11 POM 中旧 tools/jconsole systemPath 报 warning / 模型诊断，但本轮 Maven 命令 exit 0；未整体升级连接池。
- 带标签筛选的 SQL 有 JSqlParser count 优化警告，回退计数后本样本 total=1；没有证明复杂大表计数性能。
- ChunkCacheService 同步 save 后仍尝试 saveBatch，会记录重复分片主键错误；当前 smoke 仍完成，未覆盖失败恢复和并发语义。合并代码计算 MD5 后未比对请求哈希，留给上传完整性后续任务，不能声称全面哈希校验。
- categoryid 的 JPA Integer / 资源 Long Java 类型差异仍在；未开启 Hibernate validate。当前新 schema 不是既有库的数据迁移。
- 只实跑原生 MySQL；Compose 机器无 Docker 未执行。没有 SMTP、真实邮件、全部管理员 / 审核、人工浏览器试听、重启后续传、并发与负载验证。
- 合成 MPEG 验证不是音乐素材集，也不是多模态质量评估。模型维度、准确率、检索 P95 / 吞吐仍未测。
