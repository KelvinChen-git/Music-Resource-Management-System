## 改动与边界

- 资源文件移除 Anonymous，原始下载移出 JWT 排除列表；查询当前数据库账号（含锁定 / 删除 / 降权），按 CONTRACTS A4 检查资源审核与删除状态。匿名 401、锁定 403、不可见 404；有合法身份也不能获取 deleted 资源。
- 正常用户可访问 approved，资源所有者可预览自身 pending；管理员可预览 approved / pending / rejected；未知状态拒绝。原始上传按 file_path 查全部资源引用，已删除关联不当作 orphan；未关联的完整上传仅管理员下载。
- 删除 uploads 的磁盘静态映射。保留 users.avatar 引用、无音乐资源关联的 JPEG / PNG / GIF，校验格式 / 5MiB / 真实受控路径，拒绝符号链接和重复分隔符别名伪装。音乐静态路径始终不提供文件；任意字符串写进 avatar 不构成音乐权限。
- 正常 / 拒绝 / HEAD / Range 返回 private, no-store、Vary Authorization、nosniff。路径拒绝绝对路径、..、反斜杠和根目录外符号链接；不再返回一年缓存或跨域通配。播放计数在授权及物理存在检查后执行，HEAD / Range 不计数。
- ZIP 导出也检查当前账号与逐条可见性 / 路径。metadata 解析 / 保存先检查已有 file_path 引用，避免把不可见的 pending / rejected / deleted 字节重新绑定成自身 pending 来下载。
- Vue 的播放 fetch、音乐列表下载和文件管理下载使用存储的 JWT、no-store、拒绝重定向。下载直接消费 Blob，修复旧 res.data 与直接 a.href 未携带 JWT 的问题。无令牌不发媒体请求。

没有 schema 或依赖锁变更。普通资源所有者是 music_resources.userid；file_upload 仍无持久 owner，尚未关联的上传首次归属、抢先绑定和上传写操作授权需要后续所有权任务。因此本批不是整个上传系统授权完成，公开 discovery 仍保持阻断。已下载或旧一年缓存的副本不能由新响应头追溯撤销。
