## 改动

新增 `file_upload.owner_user_id`，新分片上传 / 普通上传由当前有效数据库账号赋值，忽略请求中的伪造 owner。上传列表、MD5 check、详情、进度、缺片、分片、合并、删除、元数据解析 / 绑定只允许当前所有者；管理员没有文件管理越权例外。锁定 / 失效账号分别 403 / 401，他人、未知、NULL owner 或已删除上传 404。列表排序使用固定字段白名单。

分片 / 合并、元数据首次绑定和删除在上传行锁后检查持久所有者。已有资源的审核 / 删除防重绑定继续生效，相关引用使用锁定读取，避免等待上传行锁后继续使用旧快照。真实多请求并发尚未验证。

头像也属于文件绑定：目标账号只能登记自己已完成的图片上传。不能通过 profile 写入他人的图片路径将其公开；既有旧头像保持原值可保留。被音乐（含 deleted）或头像引用的上传返回 409，未引用的自有上传只逻辑删除，保留字节和分片，避免破坏回收恢复或共用路径。物理垃圾回收尚未实现。

已有音乐媒体继续按 CONTRACTS A4 的当前账号 / 审核 / 删除策略读取。无资源引用的完整上传仅持久所有者可下载；NULL owner 旧 orphan 不开放给管理员。读取 approved 音乐不授予原上传的续传、合并或重新绑定权。
