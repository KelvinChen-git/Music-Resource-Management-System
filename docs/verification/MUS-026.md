# MUS-026：审阅底栏显示与手动播放进度

用户反馈整曲试听没有显示在系统底栏，页面也不能调节进度。原审阅helper独立持有audio，而底栏只读取普通曲库store；本任务在两者间登记临时控制会话，并添加页面range input。

实现 `d766dcd09df3cc1e54130ca80aefb946985ee2b3`，比较/范围基线 `0ae63f9d6a4632ffbfa1c0cedc017aad6cea862c`，分支`fix/MUS-026-review-player-controls`，owner A，review待B复核。契约见CONTRACTS E3，机器证据见[MUS-026-results.json](MUS-026-results.json)。

## 结果

- 审阅开始后底栏显示候选曲名、歌手和“试听审阅”，播放/暂停、进度、音量转给同一个已验证审阅audio。普通队列/历史/收藏不自动改写；审阅时禁用普通随机/循环/上一首/下一首，主动选曲库或队列曲目会撤销审阅控制。
- 页面增加“试听进度”滑块与暂停/继续。整曲可定位0..原实测时长；模型片段范围限制start..end。两个滑块同步实际时间，跳转重设终点计时；暂停保留位置并释放src/Blob。暂停时拖动重新GET/校验、仍保持暂停，继续再鉴权播放；已结束时继续从当前范围起点开始。
- 新session使普通未完成加载失效；旧发布者不能覆盖或释放新会话。取消普通切歌时清掉上一首字节，防新标题与旧音频错配。离页/换候选/导入/退出释放临时控制，原普通队列暂停保留；账号退出仍按原规则清队列。
- 原JWT/完整SHA字节验证、无pay审阅请求、失败拒播/取点、标注/草稿边界保持。没有把包当授权，也没有把标注结果改成自动评分。
