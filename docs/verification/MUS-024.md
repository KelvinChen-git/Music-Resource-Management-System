在仓库根目录执行。生成包不会加载模型、访问网络或复制音频；必须已有本机私有MUS-022工件，Git清单不能替代它们。新输出仅可在本checkout `.local/`，独占创建、0600，已有文件不覆盖。以下实际报告指纹来自原run-01，不是增补后的公开verification JSON指纹。

```sh
python3 services/audio-search/review_pack.py build \
  --run-dir .local/a/mus022/run-01 \
  --catalog web/public/demo-catalog.json \
  --report-sha256 90e7b4939cc1d77f40863403a699926881c03e41a1b634c9b4f06c23a96d9108 \
  --output .local/a/mus024/review-pack.json

python3 services/audio-search/review_pack.py validate \
  --run-dir .local/a/mus022/run-01 \
  --catalog web/public/demo-catalog.json \
  --report-sha256 90e7b4939cc1d77f40863403a699926881c03e41a1b634c9b4f06c23a96d9108 \
  --pack .local/a/mus024/review-pack.json
```

该正式包已生成，重复第一条命令会预期失败。人工工作副本请以另一个尚不存在的`.local/a/mus024/review-draft-01.json`为output再次生成，然后编辑该副本；validate的pack参数相应更换。不要直接把模型分数或建议区间转换成人工判断。
