## 启动入口

新增 `scripts/baseline.py`，从一个账号的独立 clone / worktree 根目录运行：

```bash
python3 scripts/baseline.py --slot a --keep-running
```

B 在自己的独立 checkout 将 a 改为 b。可先用 `--check` 只检查；`--offline` 只使用现有 Maven/npm 缓存；`--mysql-base /path/to/mysql` 指定原生发行目录。需要 JDK 17、项目 Node 版本、MySQL 8.0.41；在本机可识别此前下载的 `.music-tools`，其他机器自行提供安装路径。

执行顺序：

1. 只在全新 slot 创建私有配置；已有配置保留。检查库名、账号、回环地址、端口、代理与上传目录，拒绝多个账号复用同一 checkout。
2. 检查监听 / 连接权限；受限时在任何数据库初始化前停止。
3. Java 单测、前端 build；缺 node_modules 时执行 npm ci，已有安装不重复清理。
4. 若数据库已监听，使用当前应用凭据连接并保留其生命周期；否则启动该 slot 的原生 MySQL。仅不存在的数据目录允许初始化；新目录配置独立应用库 / 用户 / root 密码。已有数据目录和已有凭据不被覆盖。
5. 只有数据库完全空白才调用既有 init-db；非空库须有 11 表和 version=1，部分库明确停止，不自动修复或 DROP。
6. 启动 Java 与 Vite；未登录 profile 返回 401、前端首页返回 200 后，直连 / 代理各完成既有 13 项 smoke 才标 passed。
7. 输出私有日志目录与 result.json。默认结束时停止本次启动的进程；`--keep-running` 保持开发服务，Ctrl+C 停止。脚本不关闭外部已有 MySQL，不删除数据库 / 数据目录。

前后端接口、schema、锁文件没有更改。完整启动分支已在用户普通终端通过，8 项保护测试与真实运行证据分别列出；受管进程本身仍不能发起回环检查。
