# SONORA 独立 UI 预览

任务 MUS-018，设计分支 `design/MUS-018-ui-preview`，基于 `d34f282a499b3e93c94f90c83c38d35dcb21ca3a`。

直接用浏览器打开 `index.html` 即可体验，页面内含样式、脚本、数据和原创 SVG 概念封面，无外部字体或图片依赖。也可在仓库根目录运行：

```sh
python3 -m http.server 5188 --bind 127.0.0.1 --directory design-previews/sonora
```

然后访问 http://127.0.0.1:5188 。

深色音乐档案风格，采用暖白文字、琥珀色重点和黑胶唱片主视觉。包含曲库、歌手资料、收藏、最近播放、搜索、风格筛选、排序、封面/列表视图、详情抽屉、队列与文件选择弹窗。

这是交互设计原型，未修改 `web/`，不调用后端、数据库或上传接口。播放器只演示状态和进度，无音频播放。选择的文件仅在页面内展示。收藏只保存在独立命名空间的浏览器 localStorage；最近播放只在内存中保存。

曲库使用 19 首精选公开授权歌曲的资料，概念封面为本原型绘制，不冒充原专辑封面。Post Malone 与 Drake 各 10 条资料提供原有官方页面链接，无完整音频。114 MB 是已有演示导入批次的总量参考，并非本原型占用。

已检查桌面 1440px、窄窗口 660px、手机 390px 布局；手机无横向溢出，修复了主视觉文字与唱片图重叠。已点击核验搜索、收藏、列表切换、详情、歌手页、导入弹窗与播放状态；浏览器未记录 JavaScript error。文件选择后的实际上传不属于此原型。

截图：`desktop-preview.png`、`mobile-preview.png`。现有应用、后端、数据库与 B 的 MUS-017 审核任务不变；须先由用户确认设计，再另立接入任务。
